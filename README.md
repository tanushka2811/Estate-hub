# Estate-Hubs 🏗️

A professional, high-performance real estate web application built with a modern tech stack. Designed for speed, scalability, and an exceptional user experience.

## 🚀 Technologies Used

- **Core**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **State Management**: [Redux Toolkit](https://redux-toolkit.js.org/)
- **Routing**: [React Router 7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## ✨ Key Features

- **Dynamic Property Listings**: Seamlessly browse and filter real estate listings.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewports.
- **Performance Optimized**: Leveraging Vite and React 19 for lightning-fast load times.
- **Type-Safe Development**: Robust TypeScript implementation for better maintainability.
- **Global State Management**: Centralized data handling using Redux Toolkit.

## 🛠️ Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (LTS version recommended) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Estate-hub
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

### Development

Run the development server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

Create a production build:
```bash
npm run build
```
The optimized files will be in the `dist/` directory.

## 📂 Project Structure

- `src/components`: Reusable UI components.
- `src/features`: Feature-specific logic (e.g., properties).
- `src/store`: Redux store configuration and slices.
- `src/assets`: Images, fonts, and static resources.
- `src/data`: Mock data and constants.
